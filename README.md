# Dental CRM

> Веб-приложение для управления стоматологической клиникой — пациенты, врачи, расписание, услуги, финансы и внутренние задачи.

---

## Возможности

| Модуль        | Описание                                              |
| ------------- | ----------------------------------------------------- |
| **Dashboard** | Статистика клиники, графики доходов, ближайшие записи |
| **Пациенты**  | CRUD, поиск, фильтрация, карточка с историей визитов  |
| **Врачи**     | Список специалистов, расписание, статистика           |
| **Записи**    | Календарь приёмов, статусы, перенос и отмена          |
| **Услуги**    | Каталог стоматологических услуг с ценами              |
| **Финансы**   | Платежи, аналитика, графики по периодам               |
| **Задачи**    | Kanban-доска с Drag & Drop для сотрудников            |

## Архитектура

Проект построен по методологии **[Feature-Sliced Design (FSD)](https://feature-sliced.design/)** — слои изолированы, зависимости направлены строго сверху вниз.

```
src/
├── app/              # Роутинг Next.js, providers, стили, layout
│   └── (dashboard)/  # Страницы CRM
├── widgets/          # Крупные UI-блоки (sidebar, header, таблицы, графики)
├── features/         # Пользовательские действия (создание, редактирование, фильтры)
├── entities/         # Бизнес-сущности (patient, doctor, appointment...)
└── shared/           # Переиспользуемый код (ui, api, hooks, utils)
```

## Быстрый старт

### Требования

- Node.js 20+
- npm

### Установка

```bash
git clone <repository-url>
cd dental-crm
npm install
```

### Запуск

Нужны **два терминала** — фронтенд и mock API:

```bash
# Терминал 1 — Mock API (порт 3001)
npm run server

# Терминал 2 — Frontend (порт 3000)
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

### Другие команды

```bash
npm run build    # Сборка production
npm run start    # Запуск production-сервера
npm run lint     # Проверка ESLint
```

## API

На первом этапе используется **json-server** с данными из `server/db.json`.

| Метод    | Эндпоинт        | Описание          |
| -------- | --------------- | ----------------- |
| `GET`    | `/patients`     | Список пациентов  |
| `POST`   | `/patients`     | Создать пациента  |
| `PUT`    | `/patients/:id` | Обновить пациента |
| `DELETE` | `/patients/:id` | Удалить пациента  |

Аналогичные эндпоинты для: `doctors`, `appointments`, `services`, `payments`, `tasks`.

Base URL: `http://localhost:3001`

```

/finance                   → финансовая аналитика
```
